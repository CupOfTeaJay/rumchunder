# Rumchunder

This repository is a WIP. My end goal is to implement map generation for a game 
that I am making by leveraging shaders. Currently, there is just 3D Simplex
noise. Next steps are to:
* Add 3D Worley noise
* Add fractal brownian motion for both Worley and Simplex impls
* Try to see if I can implement diffusion-limited aggregation (DLA) for some
  mountain ranges
